# 1.6.1

- 修复兵种拖动的输入接入：移除依赖面板反向引用和按钮启停回调的旧处理器，改由统一控制器按实际鼠标命中识别兵种。
- 超过拖动阈值后才进入排序，阻止松手时误触兵种选择，保留普通点击。
- 保留插入线、边缘滚动、取消操作和独立排序文件，不需卸载派系滚动 Mod。

# 1.6.0

- 固定 +/- 刻度改为 << / < / > / >> 分级增减，单箭头 1%、双箭头 10%，整数至少变化 1。
- 加入设置面板，可即时切换并记住浅色极简或经典深色风格；两者都保留大字号和本版功能。
- 管理器声明五类扩展前置，运行时均为软依赖，不安装或停用扩展仍可编辑原版。
- 来源扫描仅追踪实际活动插件，无扩展时不等待剩余核心的模组目录。
- 手工更新同步已登记编辑器的管理器元数据，不改变其他模组的启停。
- 保留 1.5.0 兵种拖动排序、原有数值与预设格式。

# 1.5.0

- 数值框新增「− / ＋」微调，支持 Shift 十倍步长和 Ctrl 小数精调；批量数值共用控件。
- 打开“更多派系”后可拖动派系内兵种图标排序，带插入线、边缘滚动与独立持久化。
- 保留顶部派系标签原生拖拽及保存，不改变兵种归属。
- 新增“还原兵种排序”确认入口；旧数值和预设格式不变。

# 1.4.0

- 新增 Holiday 与 AnimalKingdom 编辑来源。
- 重做浅色分栏界面、统一大字号、移除说明段落和小字。
- 保留分组、草稿、批量、历史及范围预设。
- 增加可本地导入 r2modman 的标准模组 ZIP。
- 不携带用户配置，不改变旧四来源的稳定标识。
