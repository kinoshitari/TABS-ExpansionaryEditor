# 数值编辑器

游戏内按 **F6**。

## 导入 r2modman

1. 选择 TABS 和目标配置。
2. 打开“设置”，选择“导入本地模组 / Import local mod”。
3. 选择 **Local-ExpansionaryEditor-1.10.0.zip**，不要解压或改名。
4. 启动模组版游戏。

若之前使用手工安装版，请使用原来的配置。包名仍为 Local-ExpansionaryEditor，插件 GUID 和数值目录不变。

## 七个来源

原版、HiddenUnits、臭臭、Expansionary、Holiday、AnimalKingdom、Chinese_myth。

圣诞节对应 **Holiday 2.2.1**，动物王国对应 **AnimalKingdom 1.0.4**，中国神话对应 **Chinese_myth 0.2.1**。管理器将这六类扩展列为前置，BepInEx 也在前置中。插件端均为软依赖：未安装或停用扩展时仍可编辑原版。只有要编辑的扩展需要启用，本包不捆绑第三方兵种文件。

只用原版时保留 BepInEx 和编辑器即可。不希望管理器解析扩展前置时，将 ZIP 内的编辑器 DLL 放入当前配置的 `BepInEx/plugins/Local-ExpansionaryEditor`；不要保留重复 DLL。

## 编辑

- 属性、独立承伤页、左右手、可识别技能。
- 同款双持可在任一侧点“同步到另一只手”，复制整侧草稿、特殊效果及还原，仍需保存。
- 右手／左手 → 特殊效果：切换并调整武器已有的寒冷、燃烧／持续伤害、流血、雷电等附加词条，不关闭普通命中伤害。
- 补全兵种中文名称，侧栏与标题标出衍生兵种的主兵种。
- 承伤：四类伤害、燃烧／持续伤害、爆炸、冰冻积累、部位命中、模组扣血来源与护甲设置。
- 中国神话独立分组，支持护甲强度、金箍棒伸缩冷却、旋转与推进速度。
- 数值框 `<< / < / > / >>` 分级增减：单箭头 1%，双箭头 10%；整数至少变化 1，零值按基数 1 起调。
- 顶部“设置”可切换浅色极简与经典深色，自动记住选择，保留草稿与数值。
- 打开游戏“更多派系”后拖动兵种图标排序，支持边缘滚动并自动保存；顶部派系标签保留原生拖拽。
- 批量乘算、设值、增减与预览。
- 全局、Mod、派系预设及历史恢复。
- 支持日文输入法的组合输入与全角数字。

价格立即更新，其他数值需重新摆放兵种或重开关卡。

双手同步会覆盖另一侧对应修改，按同一原始武器资源识别，不按显示名称。寒冷值是积累，燃烧值是每层持续伤害基数；未知状态只显示开关，不虚构数值。关闭仅阻止后续施加，不清除已有状态，也不向无词条的武器注入元素。

## 伤害抗性

倍率 1 不变、0.5 半伤、0 不扣该路径伤害。治疗不缩放。冰冻项调新增积累量，不是冰箭命中伤害；不清除已有冻结。类型与来源倍率相乘，同一来源不重复累计。

模组来源按实际启用程序集的 `TakeDamage` 调用识别。绕过原版受伤入口、直接写生命或强制死亡的脚本不自动重写。内部模板和找不到主兵种引用的条目会明确标出。

来源项下点 **注释**，查看来源模组、机制和已确认的预制体关联兵种；再展开 **调用入口** 查看组件和实际接入方法。默认收起，使用正常字号和“（…）”括号；主兵种等从属备注同样加括号。负伤害治疗会单独说明，承伤倍率不缩放回血；停用来源保留原程序集与组件标识。

新抗性保存到可选 `Resistances` 字典，原有数值与预设格式保持不变。不要用旧编辑器重新保存新抗性配置。

武器效果使用原 `Components` 字典；新效果路径需要 1.10.0 或更新版本。回退前先还原新效果项或选用不含这些项的历史记录。

详细机制和覆盖范围见同包的 [伤害类型](伤害类型.md)。

## 菜单排序

先关闭 F6 编辑器并打开原生“更多派系”。按住兵种图标移动，超过拖动阈值后显示蓝色插入线，松开自动保存并就地更新列表，保留当前页和选中兵种；普通点击仍正常选择。同一派系内调整显示顺序，不改变归属。Esc、切换派系或关闭面板取消拖动。

F6 → 预设 → 管理 → 还原兵种排序，可确认恢复所有兵种的原生顺序。排序独立保存在 `BepInEx/config/ExpansionaryEditor/菜单排序.json`，不随数值预设导入或导出。

## 数据

原有配置仍位于当前配置的 `BepInEx/config/ExpansionaryEditor`。主数值格式保持版本 1，已有全局与局部预设继续读取。本包不含数值、预设或界面配置，不会用一份空配置覆盖现有内容。
